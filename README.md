Основной функционал:
- Личный кабинет авто
- Поддержка нескольких авто
- Журнал работ (когда, что, где, артикулы, аналоги, цена з/ч, цена работ)
- Создание новой записи в журнале
- Удаление записи в журнале
- Редактирование записи в журнале
- Поиск в журнале по словам
- Напоминание о работах
- Итоговый годовой подсчет расходов
- Графики расходов

Дополнительный функционал:
- Экспорт в xlsx или pdf
- Импорт из xlsx


Технические требования
- pwa
- сервер
